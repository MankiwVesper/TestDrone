# TestDrone
采用Python+PyQt5编写的数据处理工具。核心作用分为两个：
1. 提取数据：在实际环境中抓取的数据通常是pcap格式，通过该软件可以从pcap格式的文件中，提取出想要的UDP报文中的有效数据，方便后续自由使用；
2. 发送数据：该工具支持直接发送以太网数据。实际测试过程中， 在将数据提取出来之后，可以直接进行发送，非常方便
